Power BI: análisis de vuelos

Con un dataset de vuelos de aerolíneas de todo Estados Unidos hicimos la limpieza, un proceso ETL completo con Pentaho y un Data Warehouse. Encima construí dashboards en Power BI para analizar puntualidad, retrasos y cancelaciones.

Dataset de vuelosLimpiezaETL en PentahoData WarehouseDashboards Power BI

El Data Warehouse y los dashboards convierten datos operativos en un entorno visual e interactivo, útil para evaluar el desempeño de la operación aérea y como base para analítica avanzada o modelos de Machine Learning.
